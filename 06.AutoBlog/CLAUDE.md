# AutoBlog 프로젝트 안내

이 저장소는 티스토리("생생꿀정보통", 근로기준법/퇴직금/임금 등 실용 금융정보 니치)와 네이버 블로그의
발행 큐 + GitHub Actions 알림 시스템입니다. 전체 배경과 로드맵은 `README.md`를 참고하세요.

## 새 글을 써달라는 요청을 받으면

1. `content/tistory/ideas.md`에서 아직 사용하지 않은 주제를 우선 고려하거나, 사용자가 지정한 주제로 작성합니다.
2. `content/tistory/queue/YYYY-MM-DD-slug.md` (티스토리) 또는 `content/naver/drafts/YYYY-MM-DD-slug.md`
   (네이버) 형식으로 파일을 만듭니다. frontmatter 필드는 `README.md`의 "새 글 추가하기" 섹션을 그대로 따릅니다.
3. 품질 게이트(`scripts/lib/qualityGate.ts`)를 통과하려면:
   - 본문 1,500자 이상 (근로기준법/세무 등 YMYL 인접 주제라 얇은 콘텐츠는 구글/네이버 품질 평가에 불리함)
   - "본 글은 정보 제공 목적이며 법률·세무 자문이 아닙니다" 류 면책 문구 포함
   - category, tags 필수 입력
   - 기존 `published/` 폴더의 글과 slug/title 중복 금지
4. 문체: 실용적이고 친근한 존댓말, 과장된 클릭베이트 제목 지양, 계산 공식/절차는 번호 목록으로 명확히 정리.
   법률·세무 관련 수치는 확인 가능한 일반 원칙 위주로 작성하고, 특정 연도의 세율·금액처럼 자주 바뀌는
   구체적 수치는 확실하지 않으면 단정적으로 쓰지 않습니다.
5. 네이버 글에는 본문 흐름상 자연스러운 위치에 티스토리 링크를 1개 정도만 넣습니다 (과도한 외부링크는
   네이버 저품질 트리거).
6. `**굵게(괄호 포함)**`처럼 볼드 구간 안에 괄호를 넣으면 `formatForTistory.ts`가 쓰는 marked 렌더러가
   볼드 처리에 실패하고 `**`가 그대로 노출되는 버그가 있습니다. 괄호는 볼드 밖으로 빼서 작성하세요
   (예: `**민사소송**(지급명령 등)`).

## 발행 케이던스

`config/cadence.json` 기준 티스토리 주 4회, 네이버 주 2회입니다. 이보다 무리하게 늘리지 않습니다 —
볼륨보다 꾸준함과 품질이 우선입니다 (자세한 이유는 `README.md` 참고).

## 코딩 스타일 (scripts/ 디렉토리 수정 시)

- TypeScript, 2칸 들여쓰기, ESM (`.js` 확장자로 상대 임포트)
- 주석은 한국어로, 꼭 필요한 경우에만 작성
