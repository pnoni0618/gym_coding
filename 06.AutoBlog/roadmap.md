# 로드맵

이 문서는 진행 상황에 따라 계속 갱신됩니다. 최초 요청 원문은 `prompt.md`에 그대로 보존하고,
이후 전략/결정 변경사항은 여기에 기록합니다.

## 목표

1. 애드센스 월 $100 수익을 자동화된 시스템으로 재현·안정화
2. 티스토리("생생꿀정보통")를 근로기준법/임금/퇴직금 등 **노동법·금융 실용정보 전문 블로그**로 재정립

## 현재 상태 (2026-08-26 기준)

- 티스토리 총 72페이지 규모. 오래된 글(약 60페이지 이후)은 **제주도 가족여행 콘텐츠**, 최근 글은 **노동법/임금 콘텐츠** — 주제가 혼재된 "잡블로그" 상태 확인.
- 1단계 자동화 시스템(콘텐츠 큐 + 품질게이트 + GitHub Actions 발행 리마인드) 구축 완료.
- 큐에 발행 대기 글 2편: "2026년 최저임금 확정 총정리", "퇴직금 계산방법 완벽정리".
- GitHub Actions 워크플로가 처음에 잘못된 경로(`06.AutoBlog/.github/workflows`)에 있어 인식되지 않던 버그를 저장소 루트로 옮겨 수정.

## 리스크 / 가정

- **기존 애드센스 $100×3 달성은 여행(제주도) 콘텐츠 시기의 실적이며, 노동법/임금 니치는 아직 수익이 검증되지 않았다.** 즉 지금 하는 일은 "검증된 니치 재현"이 아니라 "새 니치 실험"이다. 첫 달 트래픽/수익 데이터로 이 가정을 검증해야 한다.
- 사이트 주제를 여행→노동법으로 재정립하면 구글이 사이트를 다시 평가하는 데 시간이 걸릴 수 있다(통상 몇 주~몇 달).
- 티스토리/네이버 모두 외부 글쓰기 API가 없어 발행은 항상 사람이 붙여넣기해야 한다 (자세한 이유는 `README.md` 참고).

- **2026-08-26**: GitHub Actions 워크플로 위치 버그 발견 및 수정 (모노레포 루트로 이동).
- **2026-08-26**: 블로그 실사 조사 결과 여행/노동법 주제 혼재 확인. 향후 방향을 **노동법/임금 실용정보로 집중**하기로 확정 (여행은 레드오션, 이미 자동화 시스템이 노동법 니치로 구축됨).

- [ ] 티스토리 관리자 페이지에서 여행/제주도 카테고리 게시글 수 확인
